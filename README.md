# Filevia 🚀

Aplikasi Flutter untuk kompresi file (.zip) dan konversi format gambar (PNG/JPG) dengan mudah dan cepat.

## Fitur
- **Kompresi File**: Bungkus banyak file sekaligus ke dalam arsip ZIP.
- **Konversi Gambar**: Ubah format gambar antara PNG dan JPG.
- **Multi-platform**: Tersedia untuk Android (.apk) dan Windows (.exe).

## Download
Unduh versi terbaru untuk Android dan Windows melalui [Halaman Releases](https://github.com/valynlove/filevia/releases).
